# **App Name**: Braxk.io

## Core Features:

- Playroom Multiplayer Logic: Real-time state synchronization using the Playroom SDK, allowing real players to join rooms instantly via shared links and custom party codes, replacing static invite buttons.
- Adaptive AI Bot Tool: An AI-powered system that uses a reasoning tool to dynamically scale bot difficulty from beginner to pro based on the skill level of active players in the session.
- The Five Heroes Matrix: A character system featuring Krayon, Blaze, Vamp, Ghost, and Titan, utilizing a specialized render logic for distinct head (256x256) and body (256x512) skin textures.
- 40-Gun Inventory System: A comprehensive arsenal divided into 10 Heavy, 10 SMG, 10 Pistol, and 10 Melee weapons, including a custom Gun Pack integration and skin compatibility logic.
- Ultimate Q Abilities: Character-specific ultimate skills including Tactical Strike, Speed Overdrive, Lifesteal, Shadow Distortion, and Titan Shielding with integrated visual cooldown tracking.
- Kill Streak Feedback System: Dynamic HUD overlay displaying an animated GIF and glowing text (e.g., '1x KILL !!') that increments with consecutive kills and resets to 1x upon player death.
- Hyper-Vibrant Combat FX: Intense arcade-style animations with neon bullet trails, particle sparks on impact, and screen shake for high-caliber weapon fire.
- Glow Respawn Engine: Seamless death interface featuring sky-colored 'YOU DIED!' text and a hyper-glowing shadowed respawn button for instant return to gameplay.
- Squad TDM & Custom Map Engine: Multiplayer environment supporting Team Deathmatch and Ranked modes using a custom map file loaded for every session.

## Style Guidelines:

- Primary Color: Electric Cyber Blue (#00A3FF). Background: Deep Graphite Void (#14161A). Accent: Power-Cell Yellow (#FFC700).
- Headlines: 'Space Grotesk'. Kill streaks: Hyper-shining red highlighted text. Death alerts: Sky-blue 'YOU DIED!' typography.
- Cartoonish aesthetic with thick, bold black outlines (cel-shaded) for all characters, guns, and a custom white crosshair PNG.
- 3D hovering lobby featuring a central floating character preview using sine-wave animations and translucent navigation panels.
- Arcade effects including skin sparkles, weapon-specific screen shake, neon ammo trails, and GIF-based kill confirmation indicators.
